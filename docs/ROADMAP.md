# Roadmap

## Milestones

### M0 — Audit + baseline
**Goal:** Understand current site structure and lock down a repeatable local build/preview workflow.

**DoD:**
- Generator/theme/content sources identified.
- Exact local preview + production build steps documented.
- No content changes yet.

### M1 — Positioning + home
**Goal:** Refresh the top-level positioning (home/landing) so it clearly reflects current role, focus, and call-to-action.

**DoD:**
- Updated hero/intro copy + navigation labels if needed.
- Tone/style consistent with existing site.
- Home page reads well on mobile/desktop.

### M2 — Research pillars
**Goal:** Present the main research themes/pillars with clear, public-facing descriptions.

**DoD:**
- Pillars listed with short summaries and links onward.
- Copy avoids internal jargon; consistent terminology.

### M3 — Projects
**Goal:** Curate active/recent projects aligned to the pillars.

**DoD:**
- Projects list with one-line descriptions and external links where appropriate.
- Clear status (active/recent) and ownership/collaborators where public.

### M4 — Teaching
**Goal:** Make teaching/supervision easy to find and understand.

**DoD:**
- Teaching overview (modules, supervision interests/approach).
- Links to relevant materials (where public) and contact route.

### M5 — Team
**Goal:** Add/refresh a lightweight team view.

**DoD:**
- Minimal bios/roles for current group members (or structure for adding them).
- Consistent formatting; avoids high-maintenance detail.

### M6 — Updates
**Goal:** Add a maintainable updates/news stream (talks, papers, workshops, announcements).

**DoD:**
- Simple format (low overhead) and at least a few seeded entries.
- Clear how to add a new update.

### M7 — Polish + deploy
**Goal:** Merge-ready quality: build clean, links work, and deployment expectations are clear.

**DoD:**
- Local build clean; no broken links; basic accessibility sanity pass.
- Netlify/deploy settings verified.
- `docs/STATUS.md` updated with final headSha.
