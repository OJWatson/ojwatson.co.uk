# Roadmap

## Milestones

### M0 — Setup + baseline
**Goal:** Prepare branch + CI/local build commands documented.

**DoD:**
- `docs/STATUS.md` + `docs/WORKLOG.md` exist.
- Local build/preview instructions documented.
- No content changes yet.

### M1 — Content refresh (promotion baseline)
**Goal:** Update core landing/about content (title/role), ensure style matches existing site.

**DoD:**
- Updated title/role.
- Updated projects and teaching summary.
- Maintains existing design language.

### M2 — Research group + projects
**Goal:** Add/refresh pages/sections for research team and current projects.

**DoD:**
- Research team section with minimal bios/roles.
- Project list aligned to current work.

### M3 — News/updates
**Goal:** Add lightweight news/updates section (publications/talks/conferences).

**DoD:**
- A simple, maintainable updates format (e.g. Markdown list/posts).
- At least 3 seeded entries.

### M4 — Polish + deploy gate
**Goal:** Ensure build clean + links correct; merge-ready.

**DoD:**
- CI (if present) green.
- No broken links.
- `docs/STATUS.md` points at final headSha.
