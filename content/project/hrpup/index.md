hrpup accompanies the study by Watson and colleagues in *Nature Medicine* (2025), examining global risks to the reliability of malaria rapid diagnostic tests. The article’s code availability statement names this repository.

This is a study-specific research compendium, organised using an R package structure. Consult the paper and repository for the relevant versions and analysis resources.
