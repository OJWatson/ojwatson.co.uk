# Dependency notes

On 5 November 2026, the GitHub migration updated `markdown-it` to 14.3.3, the current patched 14.x release, and reran the archive/rendering checks. Published JSON bytes and record hashes are unchanged by a reader dependency update.

`turbo-stream` remains pinned to 2.4.1 to decode the public React Router wire format currently served by ChatGPT. `npm audit` reports [GHSA-rxv8-25v2-qmq8](https://github.com/advisories/GHSA-rxv8-25v2-qmq8) for this version. The advisory describes a serialization bottleneck while encoding server responses in React Router Framework/Single Fetch applications. AIRef does not run that server framework or encode turbo-stream responses: production uses the decoder in the user's browser, on bounded public provider source; `encode` is used only in synthetic tests. This is a scoped applicability assessment, not a claim that every decoder input is safe. A major-version upgrade needs a separate compatibility check against both actual ChatGPT response formats; a synthetic fixture generated by the new encoder would not establish backward compatibility.
