WHEN A LINK NEEDS A BROWSER

Bring the snapshot
with you.

Some public share pages cannot be read automatically. The AIRef helper reads the text and code already loaded in your browser and opens it directly in a new AIRef review tab. You can also save a JSON file if you prefer.

Download browser helper ↓

Install once in Chrome or Edge.

  1. Download and unzip the helper into a folder you will keep.
  2. Open chrome://extensions (Chrome) or edge://extensions (Edge).
  3. Enable Developer mode, choose Load unpacked, and select the unzipped folder containing manifest.json.
  4. Pin AIRef capture helper if you want easier access.

Capture a shared conversation.

  1. Open the public ChatGPT or Claude share link. This helper only accepts public /share/… pages.
  2. Expand collapsed messages and load earlier messages where necessary.
  3. Click the helper, then Capture and review in AIRef.
  4. AIRef opens a new tab with your transcript ready for review. No file handling is needed.
  5. Check every message, add reference details and your invitation code, then confirm publication.
Capture scope matters. This is a capture of loaded message text, not a guarantee of the full conversation. Attachments and artifacts are omitted. Review the result and acknowledge its limitations before publishing.

Updating an earlier helper

Version 0.2.0 adds direct review. Replace the old helper folder with the new download, then click its reload button on the extensions page. Reload AIRef too. If Chrome assigns a second AIRef entry, remove the older one.

What the helper can access

It uses the active-tab permission only after you click it. It does not request cookies, browsing history, AI account credentials, or access to every website. Temporary handoffs use browser session memory, expire after 15 minutes, and can be opened once by AIRef. The transcript is never put in a URL. No capture is sent to the archive server until you confirm publication.
